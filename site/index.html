PSP Pacman

This is the repository for the package manager for the Playstation Portable SDK called PSPDEV.

Packages can be installed using the following command: 

# psp-pacman -Sy package-name
Updating installed packages can be done using the following command: 
# psp-pacman -Syu

To download PSP Pacman pick the download link below for your platform:
  • alpine_x86_64
  • debian_x86_64
  • fedora_x86_64
  • macos_arm64
  • macos_x86_64
  • ubuntu_aarch64
  • ubuntu_x86_64

After downloading, set the following variables in the command line to make it usable: 

# export PSPDEV="pspdev"
# export PATH="${PATH}:${PSPDEV}/bin"
Replace "pspdev" with the full path to the extracted pspdev directory. The export commands can also be added to "~/.bashrc" on Linux or "~/.zprofile" on MacOS to make them available permanently. On Windows, use Ubuntu in WSL to use this package.
